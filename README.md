# 내 자산 현황

흩어져 있는 자산(예적금, 주식, 펀드·ETF, 가상자산, 부동산, 연금·보험, 부채)을 한 화면에서 확인하는 개인용 웹사이트입니다.
빌드 과정이나 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 기능

- **요약**: 순자산 · 총자산 · 총부채 · 투자 수익(률)
- **자산 구성**: 분류별 비중 도넛 차트
- **순자산 추이**: "오늘 기록하기"로 날짜별 순자산을 남기고 그래프로 확인
- **자산 목록**: 추가 / 수정 / 삭제, 분류별 필터, 항목별 수익률·비중
- **외화 자산**: 자산마다 통화(USD, EUR, JPY, CNY, GBP, HKD, AUD, CAD)를 정하고, "환율"에 입력한 값으로 원화 환산 (JPY는 100엔 기준)
- **스크린샷으로 추가** (Claude 아티팩트에서만): 금융 앱 잔고 화면 캡처를 Claude가 읽어 항목과 외화 금액, 화면에 보이는 환율까지 채움
- **금액 숨기기**: 다른 사람 앞에서 화면을 열 때 금액을 흐리게 처리
- **백업**: JSON 파일로 내보내기 / 불러오기

## 데이터 저장

입력한 데이터는 **사용 중인 브라우저의 localStorage에만** 저장되며 어디로도 전송되지 않습니다.
다른 기기나 브라우저로 옮길 때는 "백업 내보내기"로 받은 JSON 파일을 "백업 불러오기"로 넣으면 됩니다.
백업 파일에는 실제 자산 정보가 들어 있으니 공개 저장소에 올리지 마세요.

## 배포 (GitHub Pages)

저장소 Settings → Pages → Source를 `Deploy from a branch`로 두고 브랜치/루트(`/`)를 선택하면
`https://<사용자명>.github.io/report/` 에서 접속할 수 있습니다. (데이터는 여전히 각 브라우저에만 저장됩니다.)
